# Evosim site

The public web page of **Evosim**, an evolution god sandbox for Android, served with GitHub Pages at
<https://erdemwilkinson.github.io/evosim-site/>.

Evosim yayın sayfası: Android için evrim ve tanrı oyunu Evosim'in tanıtım ve gizlilik politikası sayfası.

| Path | Page |
|---|---|
| `index.html` | Short introduction in English and Turkish, with the contact address |
| `privacy/index.html` | Privacy policy, linked from the Play Store listing |
| `.nojekyll` | Serves the files as they are, without Jekyll |

The pages are plain HTML with inline styles: no build step and no scripts. Push to `main` and
GitHub Pages publishes the change.

The browser version of the simulation is [evosim](https://github.com/ErdemWilkinson/evosim).
